# Vector Calculator in Python with NumPy

## 📝Description
A console vector calculator implementing basic linear algebra operations using NumPy. Created as a learning project to understand element-wise operations and dot product.

## 🚀 Features
- **Vector Addition**: Adds two vectors element-wise.
- **Scalar Multiplication**: Multiplies a vector by a scalar value.
- **Dot Product**: Calculates the dot product of two vectors.
- **Magnitude**: Calculates the length of a vector.

## 💡 AI Connection
In neural networks, words become vectors (embeddings). The dot product measures similarity between vectors. A longer projection (shadow) means more similarity. This tool demonstrates the basic math behind cosine similarity in NLP.

## 🛠️ How to run
```bash
python main.py
```
